## Reporting a Vulnerability

If you discover a security vulnerability, security vulnerability in dependency management, or intellectual property discrepancy within this repository, please do **NOT** open a public issue.

Instead, please send an encrypted or direct email to the corresponding author:

- **Contact:** Md. Nazmul
- **Email:** `nazmulhas36@gmail.com`
- **Subject:** `[SECURITY] orbit-tied-qnbp vulnerability report`

### What to Include in Your Report
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept (PoC) code.
3. Affected versions and dependencies.
4. Proposed fix or mitigation strategy (if available).

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline prior to public announcement.
